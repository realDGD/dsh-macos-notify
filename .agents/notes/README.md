# Agent Notes — dsh-macos-notify

Agent Notes for decisions that constrain this plugin only, kept beside the code they govern.

The convention this directory follows — the lifecycle folders, the class set, the file format, and how a pre-format document is migrated into a note — is owned by the umbrella repository's [`.agents/notes/README.md`](../../../../.agents/notes/README.md) (in an umbrella checkout; this plugin is a submodule with its own remote). Read that file before writing a note here; this file does not restate it.

Notes live at `<lifecycle>/<class>/<yyyy-mm-dd>-<topic>.md`, where the date is the day the topic was first proposed in this repository's history.

A decision that constrains the umbrella — install policy, submodule policy, how plugins are catalogued — belongs in the umbrella's own notes, not here.
