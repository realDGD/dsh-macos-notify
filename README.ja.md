# DSH Notify

[简体中文](README.md) · [English](README.en.md) · **日本語** · [Español](README.es.md) · [Français](README.fr.md) · [Deutsch](README.de.md) · [Русский](README.ru.md) · [Português](README.pt.md)

**DeepSeek Harness Desktop** に macOS ネイティブ通知、承認、質問フォーム、メニューバーのセッションパネルを追加します。通知からリクエストに対応したり、該当するワークスペースとセッションに戻ったりできます。

DSH プラグインとバックグラウンドの **DSH Notify.app** で構成されます。ヘルパーは Desktop とともに起動・終了します。ブラウザー、DSH Bridge、追加のモデルサービスは不要です。コミュニティ製プラグインで、現在の安定版は **v0.5.0** です。[リリースとダウンロード](https://github.com/realDGD/dsh-macos-notify/releases/tag/v0.5.0)を参照してください。

## 機能

| 機能 | 動作 |
| --- | --- |
| ネイティブ通知 | 完了、エラー、承認、質問を通知し、クリックで対応するセッションに戻ります。 |
| クイック承認 | 通知やメニューバーから **1 回だけ許可**、**拒否**を選択できます。承認の詳細でコマンドを確認できます。 |
| 質問フォーム | 1 つの通知からすべての質問を開きます。各質問に単一／複数選択と独立したテキスト欄があり、まとめて送信できます。 |
| セッションパネル | アクティブなセッション、入れ子のサブエージェント、最近の親セッション 5 件、状態、タスク進捗を表示します。 |
| コンテキストとコード | Markdown の表、数式、コードをローカル表示します。Shell/JSON の強調表示とコマンド・引数の折り返しに対応します。 |
| 言語 | DSH に合わせて簡体字中国語、英語、日本語、スペイン語、フランス語、ドイツ語、ロシア語、ポルトガル語に切り替わります。セッション名、質問、選択肢、回答、コマンドは原文を保持します。 |

追加した 6 言語は現在のソースに含まれ、安定版にはまだ未収録です。使用するには、このソースに対応するネイティブヘルパーを再ビルドしてください。[用語とローカライズの保守](docs/localization.md)を参照してください。

リクエストの有効性は DSH が判断し、最初に受理された回答が有効になります。回答済み、キャンセル済み、期限切れのリクエストは撤回され、古いボタンから操作を繰り返せません。質問ウィンドウを閉じたり一時的に切断されたりしても下書きは保持されます。**回答をクリア**は選択と入力のみを消し、リクエストをキャンセルしません。下書きはヘルパーのメモリ内に保持され、DSH による回答・取消・撤回の確認時に消去されます。ヘルパーを終了すると未送信の下書きは失われます。結果が未確認の場合は自動再試行しません。

## インストール

**DSH Desktop のプラグイン管理からのインストールを推奨します。** macOS 13 以降、公式 DSH Desktop、Apple Command Line Tools が必要です。実行時互換性とヘルパーの状態は `0.2.2-rc.1` で確認されています。Desktop のインストールは同梱の Node.js/pnpm を使います。別途 Node.js 22 以降が必要なのは手動ビルドと開発です。旧 macOS や Intel、実際の通知クリックについての確認範囲は[互換性](docs/compatibility.md)を参照してください。

`v0.5.0` はヘルパーを自動インストールします。古い `v0.5.0-preview.1` は手動手順が必要です。追加言語を使う場合は、上記のソース版に関する注意も確認してください。

1. ターミナルで次を実行し、Command Line Tools のシステムインストールを完了します。インストール済みなら次へ進みます。完全な Xcode や有料証明書は不要です。

   ```sh
   xcode-select --install
   ```

2. Desktop の **プラグイン → プラグインを追加**を開き、次を貼り付けて出所を確認し、**インストール**を選びます。

   ```text
   github:realDGD/dsh-macos-notify
   ```

3. ビルドがブロックされた場合は内容を確認して**これらのスクリプトを許可して再試行**を選びます。ヘルパーは `/Applications/DSH Notify.app` に構築されます。同じビルドは再利用され、更新時は設定と以前のアプリのバックアップが保持されます。
4. **今すぐ有効化**を選びます。作業を保存し、**⌘Q** で Desktop を終了してから開き直します。ウィンドウを閉じるだけでは終了しません。macOS に求められたら **DSH Notify** の通知を許可します。
5. **設定 → DSH Notify** で接続と通知権限を確認し、テスト通知を送信して実際にクリックします。対応するセッションが開くことを確認してください。macOS の受理だけでは移動成功の確認にはなりません。

公式の[プラグインガイド](https://github.com/deepseek-ai/deepseek-harness/blob/master/packages/client/ui-plugin-manager/README.md)も参照してください。

### ターミナルを使う場合

Desktop のアプリメニューから **Manage dsh Command…** を使ってコマンドを導入し、新しいターミナルで実行します。

```sh
dsh plugin --profile desktop add github:realDGD/dsh-macos-notify
```

Desktop は `desktop` プロファイルを使います。`--profile web` は別の Web 環境です。ビルドスクリプトの許可が必要な場合はプラグイン管理で許可してください。[詳しいインストール手順](docs/install.md)と[公式コマンドガイド](https://github.com/deepseek-ai/deepseek-harness/blob/master/apps/desktop/README.md#terminal-command)を参照してください。

### DSH にインストールを依頼する

新しい DSH 会話に次を貼り付けられます。

```text
この Mac の公式 DeepSeek Harness Desktop に DSH Notify をインストールしてください。
https://github.com/realDGD/dsh-macos-notify
最初に README と docs/install.md を読み、DSH のバージョン、macOS 13 以降、Command Line Tools を確認してください。
Desktop の desktop プロファイルと公式プラグイン管理または同梱 dsh コマンドを使ってください。
必要な言語を含む版か確認し、プラグインと同じリビジョンの /Applications/DSH Notify.app を構築してください。
既存設定とバックアップを保持し、システムインストール、ビルド許可、通知権限で私の操作が必要な手順を説明してください。
作業保存後に Desktop を終了して再起動するよう案内し、テスト通知を送信・クリックして対応するセッションを確認するところまで進めてください。
```

### 手動インストール

古いプレビュー、自動インストール失敗、開発用です。Command Line Tools と [Node.js 22 以降](https://nodejs.org/en/download)を導入して実行します。

```sh
git clone https://github.com/realDGD/dsh-macos-notify.git
cd dsh-macos-notify
npm ci --ignore-scripts
bash macos/install.sh
pwd
```

`pwd` の絶対パスを **プラグイン → プラグインを追加**に貼り付け、有効化・再起動・テストを行います。[Releases](https://github.com/realDGD/dsh-macos-notify/releases) の完全なソースアーカイブを使う場合は展開先で `npm ci --ignore-scripts` から実行します。プラグインとヘルパーは同じリビジョンにしてください。公式アイコンは通常 `/Applications/DeepSeek Harness.app` から取得します。別の場所にある場合は[インストールガイド](docs/install.md)に従って指定してください。

### よくある問題

| 症状 | 対処 |
| --- | --- |
| `swiftc` がない | `xcode-select --install` のシステムインストールを完了して再試行します。 |
| スクリプトがブロックされる | DSH でスクリプトを許可して再試行します。 |
| `dsh` が見つからない | プラグイン管理を使うか、Desktop でコマンドを修復し新しいターミナルを開きます。 |
| バージョン非互換 | [互換性ガイド](docs/compatibility.md)で対応する組み合わせを確認します。 |
| ヘルパー未導入／更新拒否 | 手動手順を使うか、下書きを処理して承認・質問ウィンドウを閉じてから再試行します。 |
| GitHub に接続できない | 接続を確認するか取得済みの完全なソースを使います。npm レジストリ変更では GitHub リポジトリを取得できません。 |
| 通知が表示されない | **システム設定 → 通知 → DSH Notify** と集中モードを確認し、設定からテストします。 |

ヘルパーはログイン項目ではなく、Desktop とともに起動・終了します。

## 日常の操作

- 魚アイコンをクリックすると、固定済み・入力待ち・異常停止・実行中の順でアクティブなセッションを表示します。最近のセクションは重複とサブエージェントを除く親セッション最大 5 件です。
- セクションの標準件数は親セッションのみを数えます。親を展開すると最初のサブエージェント 2 件を表示し、追加表示で残りを開きます。内容に合わせて高さが増え、上限では上下矢印で移動します。ホイールやスクロールバーはありません。1 行の表示領域では親を固定しません。
- 上下キーで追加表示行を選び、Enter／Space で展開・折りたたみ、右キーでも展開できます。展開後は新しく表示した最初のサブエージェントに移り、追加表示行で左キーを押すと親に戻ります。
- タスク数は進捗リング内に表示され、計画完了時は緑のチェックになります。計画がないセッションにはリングを表示しません。承認は縦並びの許可／拒否、質問はフォームを開きます。複数リクエストは操作メニューから選択します。
- 設定で通知種類、サウンド、サブエージェント個別通知、完了待ち、表示中のセッションの通知抑制を変更できます。
- 魚を右クリックすると DSH を開く、DSH Notify の設定、メニューバー非表示、DSH 終了を選べます。歯車も設定を開きます。外側のクリックはパネルを閉じ、独立した承認・質問ウィンドウは保持します。
- タスク実行中・承認待ち・回答待ち、または状態が古い・不明・不完全な場合、終了前に確認します。通常のアプリ終了を DSH に要求します。
- メニューバーを非表示にしても通知と承認・質問ウィンドウは使えます。DSH Notify の設定で再度有効化できます。
- DSH の言語設定を変更すると、開いているウィンドウの文案も更新され、選択と下書きは保持されます。配信済み通知は送信時の言語を保持します。

コンテキストは Markdown と KaTeX でローカル表示されます。見出し、リスト、引用、表、数式、コードに対応し、外部画像は自動読み込みせず、HTML は実行しません。長文は省略上限を表示します。全文は DSH で確認してください。

## 更新とアンインストール

更新前に作業を保存し、未送信の下書きを処理して承認・質問ウィンドウを閉じます。現在のプラグイン管理では**一度削除して追加し直す**ことで更新します。自動インストール対応版はヘルパーも確認・更新します。手動版は `npm ci --ignore-scripts` と `bash macos/install.sh` を実行して同じソースを追加し直し、Desktop を通常どおり再起動します。設定と前のアプリのバックアップは保持され、旧プロセスの終了確認後に置換します。

`dsh-notify-web`／`DSH Jump.app` から移行する場合は古い通知プラグインと完了・エラーの中継を削除して重複を避けます。通知権限と互換性のため旧ヘルパーの識別子は維持されます。

アンインストールは DSH のプラグイン管理から削除し、ソースディレクトリで実行します。

```sh
bash macos/uninstall.sh
```

その後 Desktop を再起動します。設定とアプリのバックアップは保持し、このインストーラーの管理ファイルのみを削除します。

## プライバシーと制限

追加のネットワークリスナー、クラウドサービス、モデルセッションを作成しません。移動と設定は DSH の認証済み接続を使い、ヘルパーとの交換には現在のユーザー専用ファイルを使います。質問と承認はフォーム表示のため一時的にローカル保存され、診断には含まれません。不具合報告にはローカル状態、トークン、会話内容、未編集の実データ入りスクリーンショットを添付しないでください。

通知表示、集中モード、ロック画面のプレビューは macOS が制御します。通知抑制は許可・拒否・回答を自動実行しません。1 つのローカル Host／状態ディレクトリに対応します。複数 Host による共有、旧 macOS、Intel は実機未検証です。既存のローカル実機確認はメニュー展開、最近のセッションへの移動、質問再表示時の下書き保持、回答消去、DSH での回答・取消後の操作撤回を対象とし、各言語の実機検証を意味しません。
