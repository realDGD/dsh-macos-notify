# DSH Notify

[简体中文](README.md) · [English](README.en.md) · [日本語](README.ja.md) · [Español](README.es.md) · [Français](README.fr.md) · [Deutsch](README.de.md) · **Русский** · [Português](README.pt.md)

Добавляет в **DeepSeek Harness Desktop** нативные уведомления macOS, одобрения, формы вопросов и панель сессий в строке меню. Обработайте запрос из уведомления или вернитесь в соответствующее рабочее пространство и сессию.

Проект состоит из плагина DSH и фонового помощника **DSH Notify.app**. Помощник запускается и завершается вместе с Desktop. Браузер, DSH Bridge и дополнительный сервис модели не нужны. Это плагин сообщества; текущая стабильная версия — **v0.5.0**. См. [версии и загрузки](https://github.com/realDGD/dsh-macos-notify/releases/tag/v0.5.0).

## Возможности

| Возможность | Работа |
| --- | --- |
| Нативные уведомления | Сообщают о завершении, ошибках, одобрениях и вопросах. Нажатие открывает нужную сессию. |
| Быстрое одобрение | Выберите **Разрешить один раз** или **Отклонить** в уведомлении или меню; откройте подробности для проверки команды. |
| Полные формы вопросов | Одно уведомление открывает все вопросы с одиночным/множественным выбором, отдельными текстовыми полями и общей отправкой. |
| Панель сессий | Показывает активность, вложенных субагентов и пять недавних основных сессий со статусами и прогрессом. |
| Контекст и код | Локально отображает Markdown-таблицы, формулы и код, подсвечивает Shell/JSON и переносит длинные команды и аргументы. |
| Языки | Следует языку DSH: упрощённый китайский, английский, японский, испанский, французский, немецкий, русский и португальский. Названия, вопросы, варианты, ответы и команды остаются в оригинале. |

Шесть добавленных языков доступны в текущем исходном коде и ещё не вошли в стабильный выпуск. Для их использования пересоберите нативный помощник из той же ревизии. См. [источники терминов и сопровождение](docs/localization.md).

DSH определяет актуальность запроса. Действует первый принятый ответ; обработанные, отменённые и просроченные запросы отзываются, а старые кнопки не повторяют действие. Закрытие окна вопросов и краткий разрыв соединения сохраняют черновики. **Очистить ответы** удаляет выбор и текст без отмены запроса. Черновики хранятся только в памяти помощника и удаляются после подтверждённого ответа, отмены или отзыва в DSH. Выход из помощника уничтожает неотправленные черновики. Неподтверждённый результат никогда не отправляется повторно автоматически.

## Установка

**Рекомендуется менеджер плагинов DSH Desktop.** Нужны macOS 13 или новее, официальный DSH Desktop и Apple Command Line Tools. Совместимость выполнения и состояние помощника проверены на `0.2.2-rc.1`. Desktop использует встроенные Node.js/pnpm; отдельный Node.js 22+ нужен только для ручной сборки или разработки. Проверенные клики и ограничения старых macOS и Intel описаны в [совместимости](docs/compatibility.md).

`v0.5.0` устанавливает помощник автоматически; старой `v0.5.0-preview.1` нужна ручная установка. Для новых языков учитывайте примечание об исходном коде выше.

1. Выполните команду в Терминале и завершите системную установку инструментов. Если они уже установлены, продолжайте. Полный Xcode и платный сертификат не нужны.

   ```sh
   xcode-select --install
   ```

2. В Desktop откройте **Плагины → Добавить плагин**, вставьте адрес, проверьте доверие к источнику и выберите **Установить**:

   ```text
   github:realDGD/dsh-macos-notify
   ```

3. Если скрипты заблокированы, проверьте плагин, разрешите их и повторите установку. Помощник собирается в `/Applications/DSH Notify.app`. Совпадающая сборка используется повторно; обновление сохраняет настройки и резервную копию прежнего приложения.
4. Выберите **Включить сейчас**. Сохраните работу, выйдите из Desktop через **⌘Q** и откройте снова; закрытия окна недостаточно. Разрешите уведомления **DSH Notify**, когда спросит macOS.
5. В **Настройки → DSH Notify** проверьте соединение и разрешения. Отправьте тестовое уведомление и нажмите на него, чтобы проверить нужную сессию. Принятие macOS подтверждает лишь приём уведомления; переход проверяется реальным нажатием.

См. [официальное руководство по плагинам](https://github.com/deepseek-ai/deepseek-harness/blob/master/packages/client/ui-plugin-manager/README.md).

### Команда в Терминале

Установите команду через **Manage dsh Command…** в меню приложения Desktop, откройте новый терминал и выполните:

```sh
dsh plugin --profile desktop add github:realDGD/dsh-macos-notify
```

Desktop использует профиль `desktop`; `--profile web` относится к отдельной Web-среде. Заблокированные скрипты разрешаются в менеджере плагинов. См. [подробную установку](docs/install.md) и [официальное руководство по команде](https://github.com/deepseek-ai/deepseek-harness/blob/master/apps/desktop/README.md#terminal-command).

### Попросить DSH о помощи

Скопируйте в новую беседу:

```text
Установи DSH Notify в официальный DeepSeek Harness Desktop на этом Mac:
https://github.com/realDGD/dsh-macos-notify
Сначала прочитай README и docs/install.md. Проверь версию DSH, macOS 13+ и Command Line Tools.

Проверь, содержит ли версия нужный язык, и собери /Applications/DSH Notify.app из той же ревизии, что и плагин.
Сохрани настройки и резервные копии. Объясни мои действия при системной установке, разрешении скриптов и уведомлений.
Попроси сохранить работу, выйти из Desktop и открыть его заново. Проведи через отправку и нажатие тестового уведомления до проверки нужной сессии.
```

### Ручная установка

Для старых предварительных версий, сбоев автоматической установки или разработки установите Command Line Tools и [Node.js 22+](https://nodejs.org/en/download), затем:

```sh
git clone https://github.com/realDGD/dsh-macos-notify.git
cd dsh-macos-notify
npm ci --ignore-scripts
bash macos/install.sh
pwd
```

Вставьте абсолютный путь из `pwd` в **Плагины → Добавить плагин**, включите, перезапустите и проверьте. Можно скачать полный архив исходников из [Releases](https://github.com/realDGD/dsh-macos-notify/releases), распаковать и начать с `npm ci --ignore-scripts`. Плагин и помощник должны быть одной ревизии. Официальный значок обычно берётся из `/Applications/DeepSeek Harness.app`; другие пути задаются по [руководству](docs/install.md).

### Частые проблемы

| Проблема | Решение |
| --- | --- |
| Нет `swiftc` | Завершите системную установку `xcode-select --install` и повторите. |
| Скрипты заблокированы | Разрешите скрипты и повторите в DSH. |
| Команда `dsh` не найдена | Используйте менеджер или восстановите команду через Desktop и откройте новый терминал. |
| Версии несовместимы | Выберите подходящие версии по [руководству](docs/compatibility.md). |
| Помощника нет или обновление отклонено | Используйте ручную установку либо обработайте черновики и закройте окна одобрений и вопросов. |
| GitHub недоступен | Проверьте соединение или используйте скачанный полный архив. Смена реестра npm не загружает GitHub. |
| Уведомлений нет | Проверьте **Системные настройки → Уведомления → DSH Notify** и режимы фокусирования, затем отправьте тест. |

Помощник следует жизненному циклу Desktop и не является объектом входа.

## Повседневная работа

- Нажмите на рыбу. Приоритет имеют закреплённые сессии, ожидающие ввода и нештатно остановленные, затем выполняющиеся. Недавние — до пяти основных сессий без повторов и субагентов.
- Лимиты разделов считают только основные сессии. Раскрытие показывает двух субагентов; дополнительная строка открывает остальных. Высота растёт до предела, затем доступны стрелки вверх/вниз. Колесо и полоса прокрутки не используются. В области из одной строки родитель не закрепляется.
- Вверх/Вниз выбирают строку дополнительных субагентов. Enter/Пробел раскрывают или сворачивают её, Вправо тоже раскрывает. Фокус переходит к первому новому субагенту. Влево на этой строке возвращает к родителю.
- Число задач показано в кольце прогресса; завершённый план становится зелёной галочкой. Без плана кольца нет. Кнопки одобрения расположены вертикально; вопросы открывают форму. **Действия** разделяет несколько запросов одной сессии.
- Настройки управляют видами уведомлений, звуком, отдельными результатами субагентов, ожиданием их завершения и тишиной при просмотре сессии.
- Правый клик открывает DSH, настройки DSH Notify, скрытие строки меню и выход из DSH. Шестерёнка тоже открывает настройки. Нажатие снаружи закрывает панель, сохраняя отдельные окна одобрений и вопросов.
- Выход требует подтверждения при выполняющихся задачах, одобрениях, ожидающих ответах или устаревшем, неполном либо недоступном статусе. Помощник запрашивает обычный выход из приложения.
- Скрытие строки меню сохраняет уведомления и нативные окна. Включите её снова в настройках DSH Notify.
- Измените язык в DSH. Открытые окна обновят тексты, сохранив выбор и черновики. Доставленные уведомления сохраняют язык отправки.

Контекст локально отображается через Markdown и KaTeX: заголовки, списки, цитаты, таблицы, формулы и код. Удалённые изображения не загружаются автоматически, HTML не выполняется. Длинный контекст указывает предел сокращения; полный текст читайте в DSH.

## Обновление и удаление

Перед обновлением сохраните работу, обработайте черновики и закройте нативные окна. В текущем менеджере **удалите плагин и добавьте снова**. Автоматическая установка также проверяет и обновляет помощник. При ручной установке выполните `npm ci --ignore-scripts` и `bash macos/install.sh`, снова добавьте тот же каталог и нормально перезапустите Desktop. Настройки и резервные копии сохраняются; перед заменой подтверждается завершение старого процесса.

При переходе с `dsh-notify-web` / `DSH Jump.app` удалите старый плагин уведомлений и ретрансляцию завершений/ошибок во избежание повторов. Исторический идентификатор помощника сохраняется для разрешений и совместимости.

Для удаления уберите плагин в DSH и выполните из каталога исходников:

```sh
bash macos/uninstall.sh
```

Перезапустите Desktop. Настройки и резервные копии приложения остаются; удаляются только файлы этого установщика.

## Конфиденциальность и ограничения

Дополнительные сетевые слушатели, облачные сервисы и сессии модели не создаются. Навигация и настройки используют аутентифицированное соединение DSH и приватные файлы текущего пользователя. Вопросы и одобрения временно хранятся локально для отображения форм и не экспортируются с диагностикой. Не отправляйте локальное состояние, токены, беседы и несокрытые реальные данные на снимках в отчётах об ошибках.

macOS управляет уведомлениями, фокусированием и предпросмотром на экране блокировки. Тихий режим не одобряет, не отклоняет и не отвечает автоматически. Поддерживается один активный локальный Host/каталог состояния. Несколько Hosts в одном каталоге, старые macOS и Intel не проверены на реальных устройствах. Имеющиеся локальные проверки охватывают раскрытие меню, переход к недавней сессии, черновики, очистку ответов и отзыв после ответа/отмены в DSH; это не подтверждает реальную приёмку каждого языка.
