# DSH Notify 菜单栏会话面板设计

日期：2026-10-07。目标版本：0.4.0。

状态：用户已确认原生弹出面板方案；本文件等待书面设计审查。尚未开始产品代码实现。

## 目的与已确认范围

在现有 DSH Notify.app 的菜单栏入口查看会话状态，不必逐个切换 DSH 窗口。面板展示需要处理和正在运行的会话、可展开的嵌套子代理、最近 5 条历史主会话、单行内容摘要，以及任务清单的真实进度。点击会话返回对应的 DSH Desktop 会话。

复用现有助手、私有本机传输、认证导航和 DSH 设置页。现有通知、Allow/Deny、完整问答、Markdown、草稿恢复和首次接受后撤回的行为继续保留。

## 原生展示

- 使用 NSStatusItem 加 NSPopover，内容用 AppKit 构建；不增加另一个 App、浏览器窗口或 Web 服务。
- 菜单栏使用清晰的单色模板图标，工具提示为 DSH Notify。任务状态显示在面板内，不依赖颜色单独传达信息。
- 面板初始宽度约 420 点，按屏幕可用范围约束；内容高度最多 600 点并可滚动。适配浅色、深色、较窄屏幕和辅助功能文本。
- 顶部显示名称、连接状态和设置入口。正文为活动会话树及历史会话区。
- 点击菜单栏图标展开/收起；点击外部或 Escape 收起。关闭面板不停止会话、不回答问题、不关闭已有审批或问答窗口。
- 键盘可以选择会话、展开/收起节点并按 Return 打开；VoiceOver 读出名称、状态和任务完成数。

每个会话行包含：状态图形、标题、单行摘要、可选 Pin 标记、可选任务进度。标题为「工作区 · 会话名」。子代理沿用所属工作区，并以缩进和展开箭头表达父子关系；所有子代理行仍可独立打开。

主会话默认折叠子代理，展开状态在本次助手运行期间按会话 ID 保留。子代理自身也可以展开其后代。重复节点或循环父子关系不会无限递归；无法解析父节点的活跃子代理保留在「未归属子代理」区并注明关系未知，不冒充主会话或进入历史 5 条。

## 内容摘要

- 正在运行、等待回答或等待审批：显示最近用户输入的文本。子代理没有直接的人类输入时，显示其任务输入并使用对应说明。
- 已完成：显示本轮最后一个正式 assistant 文本回答。只取文字内容，不显示推理、工具参数、工具结果或原始日志。
- 异常结束或主动停止：保留最近用户输入作为摘要，状态文字说明结束类型；不把前一轮回答当成本轮成功结果。
- 摘要合并换行和多余空白，只显示一行并在末尾省略。Markdown 转成简洁可读文字，不加载图片、执行 HTML 或启用交互链接。
- 标题缺失时使用「未命名会话」；只有图片等无文字输入时使用明确占位，不伪造摘要。会话 ID 不作为正常显示标题。
- 标题在快照中最多 200 个 Unicode 字符，摘要最多 240 个；原始会话内容和提交数据保持不变。

## 状态与排序

| 状态 | 颜色与文字 | 依据 |
|---|---|---|
| 等待回答/审批 | 黄色，等待回答/等待审批 | 官方当前未完成请求，包括 continued 问答 |
| 异常终止 | 红色，出错/异常中断/输出上限 | 最新一轮正式 error、interrupted 或 max-tokens 结束事实 |
| 正在运行 | 蓝色，运行中 | 官方当前 Agent 状态及当前轮事件 |
| 正常完成 | 绿色，已完成 | 最新一轮正式 completed 结束事实 |
| 主动停止或常规取消 | 灰色，已停止 | aborted 的 user/parent 等可识别取消原因；不当成网络故障 |
| 状态未知、普通暂停 | 灰色，状态未知/已暂停 | 信息缺失或 blocked 且没有明确待操作请求 |

自动重试仍处于运行状态时保持蓝色；仅一次网络错误或短暂 Host 断连不使会话变红。新的正式轮次开始后清除上一轮错误的当前状态。崩溃后经官方冷读确认的 interrupted 才显示异常中断。无可靠结束事实的旧会话显示未知，不按 idle 猜测完成。

活动区的分组优先级：

1. DSH 官方 Pin 会话，Pin 顺序沿用官方列表。
2. 等待用户操作和异常终止的会话。
3. 正在运行的会话，包括主会话结束但后代仍在运行的树。

同级非 Pin 会话按最新活动时间倒序；时间相同以稳定 ID 排序，减少抖动。子代理保持在父节点内，按同样的优先级排序。任意后代有 Pin、待操作、异常或运行状态时，整棵树提升到对应优先级，父行用「子代理待审批」等标记解释提升原因，保留父会话自身的真实状态。

历史区显示最近 5 条普通主会话，包含正常完成和用户主动停止的会话；尚无可靠状态但有历史内容的普通会话可显示为状态未知。排除子代理、空会话、归档会话和已出现在活动区的会话，不重复凑数。按最后活动时间倒序；有正式终止事件时使用终止时间，不按读取时间排序。

已 Pin 的历史会话在顶部活动区常驻，不占下面 5 条的名额。异常主会话保持在待处理区，直至恢复运行、被归档或删除；不新增第二套「已读/清除错误」操作。

## 任务圆环

读取官方 todos 投影，按 completed 项数除以总项数计算圆环，同时显示「3/5」及辅助说明。pending、in_progress 均不计为已完成；多项并行运行允许存在。

没有任务清单、清单为空或能力缺失时不显示圆环，不推测百分比。进入 Plan Mode 本身不等于有可计算的任务清单。圆环表示任务项完成比例，不表示耗时比例或整个模型运行完成度。

父子会话各自展示自身清单，不把子代理项累加到父清单。新一轮以官方重置后的清单为准；结束后保留该轮最后的有效清单。任务清单发生新增或删减时允许比例变化。

## 数据来源与组件职责

Host 是会话事实与设置的唯一来源：

- workspaceRegistry：工作区名称、成员关系、官方 pinnedSessionIds、归档关系。
- sessions、agents、session/event：活跃会话、父子关系、运行状态和最新正式消息/结束事件。
- sessionTitle：正式会话名称；冷会话通过官方只读查询获得标题。
- sessionProjections 的 todos：结构化任务状态。
- 现有 interactions 所持有的官方审批、问答和 continued 状态：只读地提供「待用户操作」，不重新安装请求拦截器。
- sessionQuery：只读列出和观察冷会话，补全历史标题、摘要和结束状态。观察租约在完成、失败或取消时释放；不启动 Agent、不获取写锁、不改写日志。

新增模块分工：

1. 纯会话模型负责状态映射、树构建、优先级、历史筛选、摘要和进度，独立于文件和 AppKit。
2. Host 采集器负责基线、事件增量、只读历史观察、设置变化和生命周期清理，产出完整快照。
3. 独立的设置命令处理只允许修改菜单栏布尔开关，调用现有 settings.save；不与回答/审批命令混用，不接受任意 RPC 方法。
4. 原生菜单栏组件校验快照，管理状态图标、弹出面板、展开状态、可访问性和点击导航。

不为了菜单栏重构已有通知生产器或完整问答窗口；共享必须的标题/展示或请求状态时采用窄接口。

## 本机传输、性能与断连

复用现有私有状态目录，增加原子写入的 session-menu.json；目录 0700、文件 0600。协议包含版本、Host generation、递增 revision、更新时间、开关和有界会话行。菜单栏快照独立于公开诊断，不将标题、摘要、路径或会话 ID 加入 status RPC、日志报告或发布包。

快照只保留展示所需字段，不保存整段聊天、原始错误、推理或工具输入。上限为 4 MiB 和 2,000 个节点；超出时优先保留 Pin、待操作/异常、运行中的树及历史 5 条，显示「另有 N 条，请在 DSH 查看」，不无声截断。完整历史日志不为每秒刷新重复读取。

Host 事件更新短时合并，最多每秒发布一次展示变化；无变化时每两秒更新存活时间。历史发现周期不短于 30 秒，单次只读并发最多 4，缓存按官方可比较的 revision/序号失效，避免异步读覆盖更新后的活跃数据。采集器卸载时取消异步读、清理定时器并禁止后续写入。

助手复用每秒 pump 读取快照。超过 6 秒未更新时展示「DSH 未连接，内容可能过期」并弱化旧状态；不制造会话完成、失败或中断事件。恢复后整体替换为新鲜事实。同一 generation 的旧 revision 不覆盖新数据；损坏或过大的文件保留最近合法显示并提示不可用。

本次维持一个活跃本机 Host/state namespace 的支持范围，不增加多 Host 合并或远程会话聚合。

## 设置与导航

DSH「设置 → DSH Notify」新增 menuBarEnabled，默认 true。沿用现有认证 settings/save RPC、布尔验证和私有持久化。关闭后移除状态栏图标、关闭该弹出面板并停止额外历史采集；通知、原生问答和审批继续工作。再次开启自动恢复图标，无需重装。

面板设置入口提供「关闭菜单栏」「打开 DSH」及 DSH 设置位置说明。「关闭菜单栏」通过独立私有命令和 Host settings.save 完成，等待匹配的设置结果，失败时明确提示；不由助手覆盖整个设置文件。菜单栏关闭后，从 DSH 设置页重新开启。不承诺不存在的 Desktop 设置深链，也不替换官方 settings.launcher。

点击会话使用现有 Desktop 请求 ID、工作区选择、会话选择及匹配 ack 链路，不发送模型消息或自动批准请求。弹出面板收起；最近一次跳转的失败在再次打开面板时可见，成功只能由匹配 ack 确认。Desktop 不可用时给出失败，不回退到浏览器。

已有审批/问答窗口仍保持「确认目标会话后才关闭」的规则，菜单栏的收起不影响其草稿。

## 验证与发布边界

- Node 回归：Pin、父子树、子代理提升优先级、5 条历史不重复、终止时间排序、主动取消与异常、重试/断连、新轮清旧错、旧事件/异步读、标题和 Unicode 单行摘要、任务清单重置、能力缺失。
- 生命周期和传输：真实 Cordis 激活/卸载；只读租约清理；设置命令身份匹配与过期处理；私有权限、边界、损坏/过大/过期快照和恢复。
- 原生回归：实际 NSPopover/行布局、嵌套展开和滚动、键盘与状态标签、圆环数字、长中文、设置开关、断连展示、点击导航成功/失败。
- 现有 0.3.1 的通知、首次回答、完整问答、Markdown 和导航回归继续通过。
- 使用安全只读/合成 fixture 验证，不运行真实审批命令或发送模型消息。
- 构建、签名、脱敏、完整打包、独立安装/升级备份和远程 Node/macOS CI 通过后发布源码；不分发官方图标或预编译助手。
- Mac 解锁后正常重启 Desktop，验证真实菜单栏、开关、子代理展开、目标会话跳转及原通知链路。锁屏或仅组件测试不能作为完整上线验收。

## 书面设计自检

范围为现有本机助手的新会话展示层；不增加另一套 Pin、任务清单、回答功能或远程同步。排序、历史名额、未知状态、进度来源、开关默认值、设置入口和失败显示已明确。事实接口来自当前官方 DSH 0.2.0-rc.2 的类型/实现；具体实现和测试拆分留给书面实现计划。
